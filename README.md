# Currency Converter

A web application that displays daily exchange rates from the Czech National Bank (CNB). Built with React, TypeScript, and server-side rendering.

## Features

- Real-time exchange rates from CNB API
- Currency conversion calculator
- Server-side rendering (SSR) with Express
- Responsive design with dark mode support
- React Query for data caching

## Tech Stack

- React 19 + TypeScript
- Vite 7
- React Router 7
- React Query (@tanstack/react-query)
- Styled Components 6
- Express 5
- Vercel (deployment)

## Getting Started

```bash
npm install
npm run dev
```

Available at `http://localhost:5173`

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm test` - Run tests
- `npm run lint` - Run ESLint
